# 把想法，写成文字。

阅读的时候有了灵感，就顺手记下来。

点击右上角的 **铅笔** 开始编辑，或者选择 **左右对照**，一边写下 Markdown，一边看见文字的样子。

## 从这里开始

- 按 **Ctrl + N** 新建一篇文档。
- 按 **Ctrl + S** 保存你的修改。
- 使用工具栏添加标题、列表、链接和图片。
- 切换标签时，编辑内容和光标位置会保留。

> 所有编辑、草稿和版本历史都留在本机。安心写下，随时继续。

## 表格，也可以轻松修改

| 功能 | 用法 |
| :--- | :--- |
| 表格编辑 | 光标放进表格，点击工具栏中的表格按钮 |
| 图片粘贴 | 将剪贴板图片粘贴到编辑器，自动保存资源 |
| 版本历史 | 查看保存记录，恢复后再决定是否保存 |
