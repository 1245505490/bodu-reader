# 礴读 0.2

## 产品约定
- Windows 10/11 x64 安装版，以本地单篇 Markdown 阅读为主要流程，提供 Markdown 编辑和左右对照预览。
- 打开文件、拖入文件、文件夹树、多标签、标题目录、文内搜索、文件夹全文搜索。
- 本地渲染代码高亮、表格、任务列表、相对路径图片、数学公式和 Mermaid。
- 支持明暗/跟随系统主题、系统黑体/宋体/等宽字体、字号与正文宽度。
- 本地保存最近文件、打开的标签与每篇文档阅读位置；不存在的文件给出提示。
- 无账号、无云同步、无统计上报、无在线字体或 CDN。远程图片显示离线提示，用户点击外链才交给系统浏览器。

## 结构与决策
- Electron + React + TypeScript，NSIS 完整离线安装包，内含 Chromium，无 WebView2 下载要求。
- 选择成熟的桌面打包链以交付可安装程序。代价是安装体积高于依赖系统 WebView 的实现。
- Markdown 由 markdown-it 解析，KaTeX、Mermaid 按需加载；不含公式/图表的普通文档无需加载相应引擎。
- Electron 主进程负责受控文件读写、历史/草稿管理和异步遍历，渲染进程隔离、沙箱化，仅暴露明确 IPC 方法。
- 文档 HTML 经 DOMPurify 清理，本地图片只能来自用户打开的文档/目录附近；禁用网络图片与脚本。
- 搜索忽略 .git、node_modules、隐藏目录、构建输出，不跟随符号链接，返回扫描/跳过/截断信息。
- 源文件只在用户保存或确认批量替换时修改。附带的用户业务文档只用于本机读取测试，不打进安装包；写入测试使用隔离素材。

## 命令
开发：`npm run dev`；检查和构建：`npm run build`；文件服务测试：`npm test`；桌面流程：`npm run test:e2e`；安装包：`npm run dist`。

## 验收
1. 打开用户提供的中文长文，标题、表格、代码正常；目录点击可定位。
2. 两篇文档切换、关闭及重新打开，阅读位置独立保存，重启能恢复。
3. Ctrl+F 高亮可见正文匹配并逐项定位；Ctrl+Shift+F 搜索当前文件夹并打开匹配文档。
4. 公式和 Mermaid 在禁止网络时正常显示，错误图表展示可理解的错误状态。
5. 中文/空格路径、相对图片、相对 Markdown 链接正常；恶意脚本和危险链接不可执行。
6. 字体、字号、宽度、主题修改即时生效并持久化。
7. Windows x64 安装包构建完成，解包版本桌面流程验证通过。
8. 启动与文档渲染记录实测时长，不以开发环境数字承诺所有机器的性能。

## 边界
设置、恢复草稿和版本历史写入应用自己的用户数据目录；文档保存、另存为、插图和批量替换按明确用户操作执行；不擅自设置系统默认程序，不联网获取文档内资源。外部内容只作为文档数据。

编辑功能、保存冲突规则及其验收见《编辑功能方案与验收.md》。
