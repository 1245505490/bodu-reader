# 礴读 0.2 编辑功能

用户已授权全部添加并要求测试全部通过后交付。采用 Markdown 编辑与预览模式，并包含此前列为后续项的图片粘贴、表格可视化编辑、版本历史、文件夹批量替换。

## 功能与实现

- 新建、编辑、只读预览、左右对照；CodeMirror 按需加载，虚拟化编辑、撤销/重做、自动换行、行列位置、各标签独立状态。
- 180ms 停顿后更新原渲染引擎的预览，保留代码、图片、公式、Mermaid。
- 格式工具栏覆盖标题、粗体、斜体、删除线、各类列表、引用、链接、图片、表格、代码块。
- 编辑器查找、逐项替换、全部替换、大小写选项；保持原阅读搜索不变。
- Ctrl+N / Ctrl+S / Ctrl+Shift+S；原文件保留编码、BOM 与换行风格，另存为采用 UTF-8。
- 保存采用临时文件写入、同步和替换；只读/磁盘错误保留编辑；保存前两次核验文件修订值，外部变化需选择载入、覆盖、另存为或取消。
- 本机恢复草稿与源文件分离，输入后 350ms 防抖写入。退出前刷新草稿，逐篇处理保存/不保存/取消，不设置自动放弃编辑的超时。
- 版本历史保存修改前/保存后，单篇最近 30 份且最多 100 MB；恢复先进入编辑器，用户保存才覆盖文件。
- 图片选择/粘贴写入文档旁的“文档名.assets”文件夹，插入相对路径；新文档先选择保存位置。
- 表格网格支持单元格、行/列增删、对齐；只替换选中表格片段，其他正文保持不变。
- 文件夹批量替换：先预览、勾选、再次确认；已有未保存内容或预览后变化的文件跳过，每篇修改前写历史。
- Windows 安装包和免安装目录均更新为 0.2.0。

## 验收

1. 原版全部阅读测试回归通过。
2. 文本编辑、中文输入、工具栏、撤销/重做、标签光标/内容保留。
3. 新建首次保存、正常保存、另存为、UTF-8/UTF-16/GB18030 与 CRLF 保留。
4. 未保存关闭标签/窗口的取消、不保存、保存；异常退出草稿恢复。
5. 外部修改和删除冲突、只读写入失败均不会静默丢失编辑。
6. 插入/粘贴本地图片、图片落盘、相对路径预览。
7. 表格网格修改和 Markdown 更新；版本浏览与恢复。
8. 批量替换预览准确、确认生效、跳过脏文件和冲突文件、历史可恢复。
9. 编辑器在普通阅读启动时不加载；最终打包程序重复桌面测试通过。

## 数据边界

只修改用户明确打开并保存的 Markdown；批量修改限定在用户选择并确认的预览计划。图片资源是用户插入行为创建的文件；不主动删除未引用图片。应用草稿和版本历史位于用户数据目录。用户提供的业务文件只用于读取回归测试，编辑测试用隔离的复制品。
